# Releases

Every publish to players, newest first. Claude adds the row after the user says it's live (docs/workflow/RELEASING.md "After a publish").

- **Tag:** `release/<YYYY-MM-DD>` on the published commit (`-b` for a second publish the same day).
- **Covers:** the last `main` commit in the build. The next release's changes start after it.
- **Notes:** the update notes title, if this release had notes.
- **Notable:** what players got, anything switched on by config or opening by timed release, problems found afterwards (with a link to `INCIDENTS.md`).
