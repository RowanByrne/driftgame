# Painted vista (T-266)

The painted ridge layers and the cloud sea round the run (`docs/game/features/painted-vista.md`). Candidates live in `..\art\generated\painted-vista\` (outside git); previews over a plain sky, each shown twice side by side so the join shows, in `preview\` there (previews only, never uploaded).

Image tool: `tools\imagegen.ps1` (Codex built-in image generation, Codex CLI `codex-cli 0.167.0-alpha.4.1`). The tool's model version is not reported; not checked against OpenAI's newest image release this round. References are from `assets/reference/environment-mood/`, as mood only.
