# Particle sheets (T-279)

The painted sprite sheets every drift particle is drawn from: the smoke billows, the grass bits and the clods (`docs/game/features/tyre-particles.md`). Candidates live in `..\art\generated\particles\` (outside git): each fitted to its exact flipbook grid in `fit\`, and previews in `preview\`.

Image tool: `tools\imagegen.ps1` (Codex built-in image generation, through the Codex app's CLI). The tool's model version is not reported; not checked against OpenAI's newest image release this round. Every candidate came back 1254 x 1254 with a real alpha channel.

## Fitting a sheet to its grid

`fit-sheet.py` (beside this file; Python with Pillow, NumPy and SciPy) writes a NEW file from a master, never changing the master: each piece is given to its grid cell (by its solid core, so a stray lobe or halo stays with it), scaled to fit its cell less a gutter, centred, and every clear pixel takes the nearest painted colour (edge bleed) so blending and mipmaps show no fringe. Billows are 2 x 2 at 1 024 (512 px a frame), bits and clods 4 x 4 (256 px a frame).

    python assets/particles/fit-sheet.py <master.png> <out.png> <grid N>

## Round 1: three hands, one set each (T-280)

Three sets, one per medium, so a set reads as one hand: oil impasto (with the vista's picked cloud attached), gouache and soft cel (with a concept painting attached as mood). The previews are the real game in DR-Lane3: the car parked half on the tarmac and half on the grass, today's emitters with each candidate set on them through Studio's local content folder (not uploaded), a burst emitted and frozen, at noon and at night, beside today's look (`preview\all-styles.png`, `preview\style-<medium>.png`). Their light is the plan's one rule (0.8 lit, no glow); sizes and rates are tuned in step 3.
