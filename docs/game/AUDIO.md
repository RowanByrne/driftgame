> **What it is:** every sound in this game, one row each: what it's for, when it plays, its id, and where it stands. The sounds registry (docs/workflow/CODING.md `Sounds`) holds the ids the code plays; this sheet holds what was picked and why.

> **Decided so far:**
> - Sounds come from Roblox's licensed libraries first (docs/workflow/ART-PIPELINE.md "Audio").
> - When a sound needs picking, Claude offers the candidates as a question in Rocco's Workboard, each with a play button (`rocco ask ... -Audio`, rocco/README.md), and the user picks.
